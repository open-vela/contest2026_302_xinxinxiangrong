# 语音识别：后续开发说明

语音识别不是当前 UI 原型的已交付功能。本项目当前没有接入麦克风，也没有在开发板上完成录音、WiFi、TLS 或云端 ASR 验收。

后续计划链路为：

```text
麦克风硬件接入
  -> OpenVela Media Recorder
  -> PCM 音频
  -> WiFi + TLS/WebSocket
  -> 云端语音识别
  -> 主题路由
  -> AI 生成或加载知识卡
  -> LVGL 展示
```

仓内相关代码仅用于后续实验。不得把主机 Mock 测试结果描述为真实麦克风或云端服务测试；不得把 API Token 写入源码、固件或提交日志。
