# 知识闪卡主题学习

面向用户指定学习主题的短卡片阅读与回忆；CSAPP 是默认示例，主题不限于计算机系统。

## When to use
用户说“学习某个主题”“打开知识闪卡”“复习英语”或“复习操作系统”时触发。

## How to use
1. 使用 `list_dir` 检查 `/data/knowledge/` 中是否存在用户主题对应的 JSON。CSAPP 卡组内置于固件。
2. 有卡组时提示用户在已经运行的知识闪卡界面按住麦克风，说出文件名对应的主题（不含 `.json`）；语音识别成功后应用加载并显示卡片。不要再启动第二个 UI 实例。
3. 如果没有卡组，明确说明需要先由开发端制作和导入；不要假称设备已经联网生成。
4. 指导用户点击展开正文，左右按钮或滑动翻页，读后遮住答案做主动回忆。
5. 录音依赖麦克风、Media audio 核服务、WiFi 与 ASR 凭据。Agent 不读取或输出凭据文件。

## Deployment
目标路径：`/data/agent/skills/knowledge-cards-topic.md`。
完整 AI Agent 启动时扫描该目录并把摘要注入上下文；新增文件后需在支持刷新命令的 Agent 中刷新或重启 Agent。
当前提交的 AP 固件只复用 Agent 的音频与 ASR 组件，并未启用完整 Agent/LLM 循环。此文件为运行时 Skill 定义与可部署资源，尚未完成该 AP 固件上的 Agent 触发验收；应用自身按键录音不依赖此 Skill。

## Example
用户：“复习操作系统” → 检查本地卡组 → 指导在知识闪卡说“操作系统” → 展示进程与线程、文件系统卡片。
