# 知识闪卡 UI 原型

当前版本用于展示 BES2800BP 454×454 显示屏上的知识闪卡 UI：显示安全面板、卡片、中文标题与正文、逐行显示、点击展开和左右翻页。

固件使用内置演示文本，**当前未接入麦克风，未接入 WiFi/云端 AI，也没有 AI 自动生成知识卡**。`kc_voice.c`、`kc_deck.c`、`llm_client.c` 等文件是后续迭代或实验性模块，不代表本阶段已经完成对应功能。

完整构建、烧录和验收范围见仓库根目录 [README](../../README.md) 与 [技术报告](../../docs/TECHNICAL_REPORT.md)。
